# Точное соответствие утверждённому UI

Уточнение владельца: все десять PNG — разные страницы одного сайта. Это не альтернативы дизайна. Публичная главная — `01-start.png`. Первоочередная работа — публичный сайт, не свободно спроектированный кабинет. Самовольные изменения визуального решения запрещены.

## Источники

- `UI/approved/design-system/master-ui-kit.png`: палитра, типографика и элементы.
- Отдельные PNG, переданные владельцем: рабочие логотипы, favicon и базовые иконки. Они лежат в `platform/public/assets/brand/owner/` и подключаются браузером напрямую.
- `UI/approved/frontend-gold-b/01-start.png`: композиция главной.
- 02: список видео; 03: страница видео.
- 04: список Beiträge; 05: отдельный Beitrag.
- 06: Bücher & PDF; 07: отдельная книга.
- 08: Live; 09: Podcast; 10: Community.

Все исходные PNG имеют размер 1672 × 941. Desktop сравнивается в этом viewport; mobile адаптирует утверждённые блоки, без нового визуального направления.

## Реализация

- Не подменять графический логотип приблизительно нарисованной книгой или набранным заново текстом.
- Не использовать целый UI-kit или экранный макет в качестве логотипа, favicon или фона страницы. Бренд-компоненты используют отдельные PNG владельца с прозрачным фоном.
- Публичные стили изолированы от Media Desktop; административный CSS не определяет дизайн публичного сайта.
- Header, footer, карточки, панели и формы строятся как рабочие HTML-компоненты.
- Примерные авторы, цены, счётчики и LIVE-состояния из PNG допускаются только в изолированных visual fixtures. В production показывать фактические данные.
- Перед показом результата сверить положение, размеры, цвета, типографику и оригинальность графики. Не называть результат «100% совпадением» без подтверждённой проверки.

## Подключение фирменных материалов

`components.brand` подключает отдельные прозрачные PNG: вертикальный логотип по умолчанию, горизонтальный — в публичном header, знак — в компактных местах. `favicon.png` создан из предоставленной иконки приложения. Палитра, шрифты, spacing и радиусы вынесены в `public/assets/brand/ui-kit.css`. Компоненты проверяются в браузере.

Все десять страниц реализованы отдельными композициями Blade: `/`, `/videos`, `/videos/{slug-id}`, `/beitraege`, `/beitraege/{slug-id}`, `/buecher`, `/buecher/{slug-id}`, `/live`, `/podcast`, `/community`. Пустые detail-страницы доступны через `/videos/vorschau`, `/beitraege/vorschau`, `/buecher/vorschau`. Отсутствующие данные обозначены ◇ «Noch keine Daten»; блоки не скрываются. Каталоги, поиск, фильтры, пагинация, вкладки и переходы работают. Цельные макеты не используются вместо HTML. Отдельного чистого пейзажа нет: по разрешению владельца используется заменяемый временный фон `owner/desktop/wallpapers/desktop2.png` (config public_ui.hero_image / PUBLIC_HERO_IMAGE). Точное совпадение не заявляется: фон заменён, объём данных отличается.

Публикация SourceRecord требует ready + public_published и permission content.publish. Поле «Bereich auf der Website» в редакторе выбирает Videos/Beiträge/Podcast/Live/Community; по умолчанию video/short находятся в Videos, post — в Beiträge. Опросы и комментарии также публикуются явно; комментарий/чат без опубликованного родителя скрыт. Account archive_data и library_only не публикуются. События Live читают metadata.live_status (live/scheduled/ended) и starts_at, эпизоды Podcast — связанные локальные audio/video. Публичные Collections требуют metadata.public_published и public_section. Активные Product отображаются как книги, черновики скрыты. Book MediaUsage cover разрешает только картинки, sample — PDF; полный public_download PDF разрешён только бесплатной книге. Платные originals не становятся бесплатными скачиваниями.

Локальные плееры/материалы проверяют публикацию, точную связь и наличие original. Закладки, реакции, выбор опроса и прогресс сохраняются для авторизованного пользователя в public_content_states; одна запись голоса на пользователя/опрос. Новые комментарии и чат сохраняются как needs_attention для проверки, не публикуются автоматически. «Vormerken» сохраняет выбор, но не обещает email/push. Озвучивание текста использует браузер, без платного ИИ. Newsletter отключён до подключения подписки; покупка — запрос через Kontakt, не фиктивный checkout. Данных автора/оглавления/отзывов у Product пока нет: эти блоки остаются пустыми. Impressum/Datenschutz читают legal_documents, Kontakt — contact_email из Settings.

Проверки: `php artisan test --filter='PublicPagesTest|PublicWebsiteTest|ImportedContentTest'`, `node tests/public-pages-browser.mjs` в testing SQLite окружении; browser проверяет все десять экранов при 1672×941 и 390×844. `tests/public-pages-fixture.php` допускает только отдельную testing SQLite-базу с public-pages- в имени, не production. Возвращённый JSON можно передать через PUBLIC_DETAIL_ROUTES для проверки заполненных detail-страниц. Новая migration создаёт таблицу пользовательских действий; перед production migrate требуется backup через Plesk.

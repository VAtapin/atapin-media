# Geplante Aufgaben — PHP 8.4

Для этого сервера выбран планировщик Plesk. Создать две задачи внутри домена от пользователя сайта. Тип обеих: **PHP-Skript ausführen / Run a PHP script**. Команды Bash, внешний `flock` и `plesk.sh services` для этого способа не нужны.

| Поле | Планировщик | Очередь |
| --- | --- | --- |
| Beschreibung | Atapin Scheduler | Atapin Queue |
| PHP-Version | 8.4 | 8.4 |
| Skriptpfad | `httpdocs/platform/bin/cron.php` | `httpdocs/platform/bin/cron.php` |
| Argumente | `schedule` | `queue` |
| Ausführen — Cron-Stil | `* * * * *` | `* * * * *` |
| Aktiv | Да | Да |
| Benachrichtigungen | Только при ошибках | Только при ошибках |

Путь задаётся относительно каталога подписки, даже если Document root уже изменён на `httpdocs/platform/public`. Поле аргументов содержит только одно слово, без кавычек. Нажать **Jetzt ausführen** у каждой задачи и убедиться в успешном завершении.

Скрипт самостоятельно загружает приложение независимо от текущей папки и удерживает PHP `flock` для выбранного режима. Если предыдущий запуск ещё работает, новый завершается успешно, не запуская второй обработчик. Worker завершает текущую работу и выходит при пустой очереди или между заданиями после 50 секунд; лимит одного задания 3600 секунд. Новые задания могут ждать следующего ежеминутного запуска. Существующая настройка `retry_after=3660` сохранена.

Скрипт доступен только из CLI; HTTP-вызов возвращает 404. Он использует PHP, выбранный в Plesk, без запуска дочернего shell или внешней команды. Запуск обеих задач проверяется Linux CI, включая блокировку повторного запуска и обработку настоящего тестового задания.

Документация Plesk: https://docs.plesk.com/en-US/obsidian/customer-guide/scheduling-tasks.65207/

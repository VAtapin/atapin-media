# Ручной архив YouTube и последующий импорт

## Принятое решение

Полный архив канала Manna Vom Himmel владелец скачивает самостоятельно из
своего YouTube-аккаунта. Это нужно для материалов, которые публичный
сборщик не может получить из-за ограничения YouTube, проверки «not a bot»
или неполной публичной истории Beiträge.

Публичный архив сборщика остаётся отдельным снимком в
`/var/www/vhosts/mannavomhimmel.de/private/manna-youtube`. По состоянию на
11 сентября 2026 года он занял около 3.9 GB; последний отчёт показывал
частичный результат: 69 материалов обработано частично, 21 не удалось
загрузить. Его не нужно удалять или заменять ручным архивом.

## Где хранить ручную выгрузку

После скачивания распаковать исходный архив на сервере **вне** `httpdocs` и
вне Git:

```text
/var/www/vhosts/mannavomhimmel.de/private/manna-youtube-manual/<дата-выгрузки>/
```

Нельзя помещать оригиналы в `httpdocs/platform/public`, в Git-репозиторий
или в папку `private/manna-youtube` сборщика. Сохранять исходные файлы,
имена, папки и экспортированные JSON/CSV/HTML без переименования: они нужны
для надёжного сопоставления ролика с YouTube ID, описанием, комментариями и
плейлистом.

Рядом с выгрузкой добавить простой `README.txt` с датой экспорта и
источником (`YouTube Studio` или `Google Takeout`). Пароли, cookies и ключи
в этот файл не записываются.

## Что уже умеет Import Center

Текущий Import Center импортирует **структурированный архив сборщика** из
`private/manna-youtube`:

- регистрирует видео, обложки и субтитры в Media Library без публикации;
- создаёт записи с названием, описанием, YouTube ID и путями к комментариям;
- создаёт плейлисты и сохраняет точный порядок элементов;
- допускает повторный запуск: существующие media-записи не дублируются.

Запуск этого существующего импорта выполняется авторизованным пользователем
с правом `imports.manage` по адресу `/desktop/imports`: выбрать **YouTube** и
нажать Import. Результат и пропуски видны в списке Import Runs. Задача
использует уже настроенный Plesk scheduler/queue; вручную копировать файлы в
public directory для импорта не требуется.

## Что нужно сделать перед импортом ручной выгрузки

Рабочая выгрузка владельца находится в `private/youtube_zip_alle`: восемь
частей `takeout-20260911T193951Z-1-001.zip` … `-008.zip` и отдельный маленький
ZIP отчёта `takeout-20260911T193951Z-001.zip`. Оригинальные ZIP сохраняются.
Локально проверены немецкие CSV Videos, Beiträge, Kommentare и Playlists;
названия video originals не содержат YouTube ID. Неоднозначные совпадения
нельзя автоматически связывать по одному названию.

Повторный импорт известных форматов теперь сопоставляет originals по
SHA-256/размеру/MIME, сохраняет альтернативные private storage locations и
исходные версии текстов. SourceRecord объединяется по source/id без замены
принятых ручных/ИИ-правок; недостающие metadata и связи дополняются. Этот
механизм не заменяет ещё необходимый адаптер немецкого Takeout.
Просмотр и переходы к материалам должны быть локальными. Адрес YouTube
сохраняется только как служебное происхождение, не как плеер или внешний
переход для посетителя; отсутствие local original показывается явно.

Произвольная папка из YouTube Studio или Google Takeout **пока не
импортируется автоматически**. Перед первым импортом ручного архива нужна
отдельная задача: реализовать адаптер ручного формата.

Адаптер должен:

1. Читать оригиналы из `private/manna-youtube-manual/<дата-выгрузки>` и не
   копировать их в public storage.
2. Сопоставлять каждый файл с YouTube ID. Приоритет: ID из экспортированных
   метаданных, затем существующий `inventory.json` публичного архива; спорные
   файлы оставить в отчёте на ручную проверку.
3. Регистрировать видео, Shorts, обложки и субтитры в Media Library;
   переносить title, description, dates, comments и прочие метаданные в
   Source Records.
4. Импортировать плейлисты с порядком роликов, включая отсутствующие или
   чужие позиции как ссылки, а не как подменённые локальные видео.
5. Писать Import Run с количеством imported/skipped и понятным отчётом
   несопоставленных файлов. Повторный запуск должен быть идемпотентным.

После реализации адаптера его запуск будет выполняться в том же Import
Center. До этого шага ручной архив нужно только безопасно хранить: не
пытаться «подмешать» его к структуре `manna-youtube` вручную.

## Проверка после будущего импорта

В Import Center проверить статус запуска и число imported/skipped, затем
сверить несколько роликов, один Short, один плейлист, описание и наличие
комментариев с исходной выгрузкой. Импорт создаёт библиотечные записи для
review; он не публикует материалы на публичном сайте и не изменяет канал
YouTube.

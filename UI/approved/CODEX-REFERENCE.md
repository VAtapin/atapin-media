# Approved UI Reference

Эта папка содержит единственный утверждённый визуальный референс для реализации **Manna Vom Himmel**.

## Правило для Codex

При разработке публичной части и Media Desktop использовать только материалы из `UI/approved/` как визуальный источник истины.

- `frontend-gold-b/` — утверждённая серия публичного интерфейса.
- `design-system/master-ui-kit.png` — утверждённый Master UI Kit.
- `README.md` — пояснение по использованию референсов.

Все прежние UI-концепты, тестовые варианты и альтернативные preview удалены из текущей ветки и не должны восстанавливаться или использоваться как источник дизайна.

Если визуальный референс и функциональное ТЗ расходятся:

- `MASTER-TZ.md` определяет функциональность и поведение;
- `UI/approved/` определяет визуальный язык, композицию и характер интерфейса.

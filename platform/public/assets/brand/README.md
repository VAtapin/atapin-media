# Brand assets

The files in `owner/` are the separate PNG assets supplied by the owner. They retain their transparent backgrounds and are served directly by the browser:

- `logo-stacked.png` is the default logo in the public notice and login page.
- `logo-horizontal.png` is available for the public header.
- `logo-mark.png` is the compact mark used in narrow spaces.
- `app-icon.png` supplies the favicon.
- `icon-*.png` are the supplied navigation icons.

`ui-kit.css` contains only palette, type, spacing and radius tokens from the approved master kit. The master-kit sheet is kept in `UI/approved/` as a design reference and is not a public web asset.
